# Orbit Frontend

Responsive React + Vite frontend for Orbit. Includes a campus and public community social experience, a unified post composer, local demo interactions, and dark/light themes.

## Development

- `npm install`
- `npm run dev`
- `npm run build`

This is a frontend prototype. Real authentication, cross-device data, messaging, server-side media uploads and authorization must be connected to the Django REST API before production use.
